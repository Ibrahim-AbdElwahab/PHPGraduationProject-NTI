## 📝 About The Project

**Smart Clinic** is a full-stack web application designed to streamline the process of booking and managing medical appointments. It provides a seamless experience for both patients and clinic administrators, ensuring efficient healthcare management.

### ✨ Key Features

**For Patients:**
* 🔐 Secure Registration & Authentication.
* 👨‍⚕️ Browse available doctors, their specialties, and consultation fees.
* 📅 Book appointments interactively.
* 📋 Track appointment status (Pending, Confirmed, Cancelled).

**For Administrators:**
* 🎛️ Dedicated Admin Dashboard.
* ✅ Approve or cancel patient appointments in real-time.
* ⚙️ Manage doctors and clinic staff.
